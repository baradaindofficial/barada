## 1. Overview

Barada Academy's content philosophy: **practitioner-taught, AI-assisted, human-reviewed.**

Every lesson is grounded in real professional experience. AI tools accelerate production — generating outlines, refining scripts, creating slide content — but the founder reviews and approves all content before it is recorded or published.

The current production model is **founder-led** (BK Satpathy records all lessons). The long-term model (Sprint 8+) will introduce an **AI Course Factory** that semi-automates the generation of new course scaffolding.

## 3. AI-Assisted Production Workflow

### For each new lesson

**Stage 1 — Outline (AI-assisted, 10 minutes)**

Prompt to use with Claude or ChatGPT:
```
You are BK Satpathy, a senior procurement and AI professional with 19+ years of
corporate experience. You are recording Lesson [N] of [Course Name] for Barada
Academy, India's professional learning platform.

Lesson title: [TITLE]
Target learner: Working professional, 2-10 years experience, wants immediately
applicable skills.
Duration: [X] minutes

Generate a detailed lesson outline with:
- Opening hook (30 seconds — a real workplace problem this lesson solves)
- 4-6 key teaching points with examples from real professional contexts
- A practice exercise the learner can do tonight
- Closing call-to-action (1 minute)

Tone: Warm, direct, practitioner. No jargon. No theory for its own sake.
```

**Stage 2 — Script (AI-assisted, 20 minutes)**

Expand each outline point into a full word-for-word script. Use the template in Section 4.

**Stage 3 — Slides (automated)**

Slide decks are already generated by `pptxgenjs` for all 10 courses. Update the content-specific slide for this lesson.

**Stage 4 — Review (human, 15 minutes)**

- Read the script aloud once — catch anything that doesn't sound natural
- Verify all examples are from real professional contexts
- Check that the practice exercise is achievable in under 15 minutes
- Confirm the lesson respects the target duration

**Stage 5 — Record**

See Section 5 for video production guide.

**Stage 6 — Post-production (AI-assisted)**

- Upload video to YouTube (unlisted)
- Download auto-generated transcript from YouTube
- Edit transcript for accuracy (usually 5–10 corrections)
- Add transcript to the lesson player page
- Generate PDF notes from the script using Claude

**Stage 7 — Publish**

- Add YouTube video ID to `data/courses.ts` for the lesson
- Upload PDF notes and prompt pack to Supabase Storage
- Deploy updated app

## 4. Lesson Script Template

```markdown
# Lesson [N]: [Title]
Course: [Course Name]
Module: [M]
Duration: [X] minutes
Author: BK Satpathy
Status: DRAFT / REVIEWED / APPROVED / RECORDED

---

## HOOK (0:00 – 0:30)
[Open with a specific workplace problem this lesson solves.
Never open with "In this lesson, we will cover..."
Example: "Last month I had to write 14 procurement follow-up emails in one day.
After this lesson, that took me 22 minutes instead of 3 hours."]

---

## TEACHING POINT 1 (0:30 – X:XX)
**Key idea:** [One sentence]

**Explanation:**
[2-3 paragraphs. Plain language. No jargon.]

**Real example:**
[A specific scenario from a real professional context.
Never use "imagine you are..." — use "Here's what this looks like in practice:"]

**What to say:**
> [Word-for-word script in blockquote]

---

## TEACHING POINT 2
[...]

---

## PRACTICE EXERCISE (before next lesson)
[One concrete task the learner can do in under 15 minutes.
Must use the tool or concept taught in this lesson.
Example: "Open ChatGPT. Write a CRAFT prompt for the next email you have to send at work.
Post the prompt and the output in the community forum."]

---

## CLOSING (last 60 seconds)
**Recap:** [3 bullet points — one per key teaching point]
**Next lesson:** [One sentence tease for Lesson N+1]
**Call to action:** [Specific next step]

---

## PRODUCTION NOTES
- Screen share needed: [Yes / No]
- Software to demo: [List]
- Slide numbers to show: [List]
- Common mistakes to address: [List]
```

## 5. Video Production Guide

### Setup

| Item | Recommendation | Notes |
|---|---|---|
| Camera | Webcam (1080p) or phone | Logitech C920 or better |
| Microphone | USB condenser mic or lapel mic | Blue Yeti, Rode, or similar |
| Background | Clean wall or professional background | Avoid clutter |
| Lighting | Ring light or natural light from front | No backlight (window behind you) |
| Recording software | OBS Studio (free) or Loom | OBS for screen + camera; Loom for quick lessons |
| Screen resolution | 1920×1080 | Avoid 4K — file sizes too large |

### Recording checklist

```
[ ] Script reviewed and approved
[ ] Slides updated and on correct slide
[ ] Phone on silent / notifications off
[ ] Microphone levels tested (no clipping)
[ ] Camera framing: head and shoulders, camera at eye level
[ ] Browser windows closed except those needed for demo
[ ] Record a 10-second test clip and review before full recording
[ ] Export as MP4 (H.264), 1080p, 30fps
```

### Upload to YouTube

1. Go to **YouTube Studio → Upload video**
2. Set visibility to **Unlisted** (never Public or Private)
3. Title: `[Course Name] — Lesson [N]: [Title] | Barada Academy`
4. Description: lesson overview + barada.in link
5. Add to playlist: `[Course Name]`
6. Enable **auto-chapters** (YouTube will detect sections)
7. Enable **auto-captions** — review and correct after processing
8. Copy the **YouTube video ID** (11-character string from the URL)

### Adding the video to the lesson player

Update `data/courses.ts`:
```typescript
{ number: 1, title: 'What is ChatGPT...', duration: '10 min',
  youtubeId: 'dQw4w9WgXcQ',   // ← Add this
  keyPoints: '...' }
```

The lesson player reads `youtubeId` and renders:
```html
<iframe
  src="https://www.youtube.com/embed/{youtubeId}?rel=0&modestbranding=1"
  allow="accelerometer; autoplay; encrypted-media; gyroscope"
  allowfullscreen
/>
```

## 6. Audio (Voiceover) Guide

Audio files allow learners who prefer listening (commute, low bandwidth) to follow the lesson without video.

### Recording

- Record the lesson script as a standalone MP3
- Software: Audacity (free), Adobe Audition, or Garageband
- Settings: 44.1kHz, 128kbps MP3, mono
- File naming: `[slug]-module-[M]-lesson-[N].mp3`

### Upload

Upload to **Supabase Storage** → bucket: `course-audio` (public bucket).
URL format: `https://[project].supabase.co/storage/v1/object/public/course-audio/[filename].mp3`

Add the `audioUrl` field to `data/courses.ts`:
```typescript
{ number: 1, ..., audioUrl: 'https://xxx.supabase.co/storage/v1/object/public/course-audio/chatgpt-m1-l1.mp3' }
```

## 8. AI Course Factory (Future Architecture)

**Status:** Designed. Not built. Target: Sprint 8+.

The AI Course Factory is an internal tooling system that automates the scaffolding of new course content. It does not replace human review — it eliminates the blank-page problem.

### Planned architecture

```
Input: Course brief (title, target learner, learning outcomes, duration)
    │
    ▼
[Claude API — Curriculum Generator]
→ 4 modules × 4 lessons per module
→ Learning outcomes per lesson
→ Key teaching points per lesson
→ Practice exercise per lesson
    │
    ▼
[Claude API — Script Generator]
→ Full word-for-word script per lesson
→ Formatted to lesson script template
→ Saved as Markdown to Supabase Storage
    │
    ▼
[pptxgenjs — Slide Generator]
→ Branded slide deck per course
→ Title slide, module slides, lesson content slides, certificate slide
→ Saved as PPTX to Supabase Storage
    │
    ▼
[Claude API — Quiz Generator]
→ 10 MCQs per module (5 per exam)
→ Correct answers + explanations
→ Saved as JSON to database
    │
    ▼
[Claude API — SEO Generator]
→ Course page meta title, description, OG tags
→ Course schema markup (JSON-LD)
    │
    ▼
[Human Review]
→ BK Satpathy reviews all generated content
→ Edits and approves each lesson
→ Records video using the script as teleprompter
```

### Database additions needed

When the AI Course Factory is built, add to the schema:
- `public.courses` table (replaces `data/courses.ts` static data)
- `public.lessons` table (lesson metadata, YouTube ID, audio URL)
- `public.quiz_questions` table (5 questions per module)
- `public.content_jobs` table (tracks AI generation jobs)

## 9. Quality Gates

Content must pass these gates before being published to learners:

**Gate 1 — Script review (founder)**
- [ ] No factual errors
- [ ] All examples are from real professional contexts
- [ ] Practice exercise achievable in < 15 minutes
- [ ] Script reads naturally when spoken aloud
- [ ] Duration estimate is accurate

**Gate 2 — Video review (founder)**
- [ ] Audio is clear, no background noise
- [ ] Video is 1080p, well-lit, professional background
- [ ] No long pauses or excessive filler words ("um", "uh")
- [ ] Screen demos are clearly visible
- [ ] Recording matches the script

**Gate 3 — Platform review (founder)**
- [ ] YouTube ID added to `data/courses.ts`
- [ ] Transcript edited and accurate
- [ ] PDF notes cover all key teaching points
- [ ] Prompt pack contains ≥ 10 usable prompts
- [ ] Quiz questions test the right concepts
- [ ] Lesson marked as `status: 'published'` in data
